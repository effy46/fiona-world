# Slow Post assets

## Blender-authored meshes

`models/train-papercraft.glb` and `models/platform-papercraft.glb` are authored in the connected Blender, not generated by an external 3D service. Editable source: `assets/slow-post/slow-post-papercraft.blend`; build source: `scripts/slow-post/build_papercraft.py`. Albedo PNGs alongside the models are reproducible material sources and are embedded in the GLBs. All model geometry and textures are made for Fiona World. No external model credits or API keys are needed.

`autumn-maple.png` is a new AI-generated transparent cutout, generated with the built-in image generation tool on 2026-11-13. It is an original tree illustration. Reference product photographs are not used as runtime textures.
